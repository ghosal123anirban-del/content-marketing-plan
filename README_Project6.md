## 🔍 Project Overview

This project presents a complete **Content Marketing Plan** developed for **GlowSkin Co.**, a fictional Indian D2C skincare brand targeting urban millennial women. The plan covers a full 30-day content strategy for April 2026 across 4 channels — Instagram, Blog, Email, and YouTube Shorts.

The strategy is built around a **4-pillar content framework** (Educate, Inspire, Engage, Promote) with a weekly thematic structure, a detailed 40-post content calendar, multi-channel distribution plan, and full ROI tracking using HubSpot and Google Analytics 4.

## 🖥️ Interactive Dashboard – How to Use

1. Open `Content_Marketing_Dashboard.html` in any browser
2. Use the **Channel slicer** to filter by Instagram / Blog / Email / YouTube
3. Use the **Pillar slicer** to view Educate / Inspire / Engage / Promote only
4. Use the **Week slicer** to drill into any specific week
5. Click **Reset Filters** to return to the full campaign view

All KPI cards, charts, calendar, pillar bars, and content table update instantly.
